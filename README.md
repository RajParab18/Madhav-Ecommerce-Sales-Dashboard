# Madhav Ecommerce Sales Dashboard

## 📊 Project Overview
This project features an interactive Power BI dashboard designed to track, analyze, and visualize key performance metrics for an e-commerce business. The dashboard transforms raw transactional data into actionable insights, helping stakeholders monitor monthly profit trends, geographical performance, product demand, and customer purchasing behavior.

## 📸 Dashboard Preview
![Dashboard Preview](dashboard_preview.png)

## 💡 Key Insights & Features
* **High-Level KPIs:** Dynamically tracks total Sales ($5K), Cumulative Profit ($907), Total Quantity Sold (59 units), and Average Order Value ($1.898K).
* **Time-Series Analysis:** Visualizes profitability trends across months (Q1 data showcases a massive profit spike in February compared to January and March).
* **Product Performance:** Explores sales distribution by category (with **Clothing** dominating at 54.34%) and dives deep into specific sub-categories (identifying **Phones** and **Bookcases** as top profit drivers).
* **Customer Logistics & Behavior:** Maps consumer payment preferences, showing a strong reliance on **EMI (27.12%)** and **Cash on Delivery (25.42%)**. 
* **Interactive Slicers:** Equipped with dynamic filters for **Quarters (Q1–Q4)** and **States** (e.g., Andhra Pradesh) for granular data exploration.

## 🛠️ Tech Stack & Skills Demonstrated
* **Power BI Desktop:** Dashboard design, canvas layout, and data visualization.
* **Power Query:** Data cleaning, column profiling, and data type transformations.
* **DAX (Data Analysis Expressions):** Created custom measures for key metrics like Average Order Value (AOV) and conditional profit formatting.
* **Data Modeling:** Establishing clean relationships between tables for optimal report performance.
